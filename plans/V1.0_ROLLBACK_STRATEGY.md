# v1.0 Rollback Strategy

## Current Stable State (v1.0 with Fases 1-2)

This document defines the rollback strategy for the current working version.

## What Works in v1.0 (with Fases 1-2)

- ✅ Real-time transcription via Deepgram
- ✅ Live Captions show current partial (updates rapidly)
- ✅ Conversation History accumulates finals
- ✅ Speaker locked to "Interviewer" (no diarization confusion)
- ✅ Dual path: live_caption (display) + transcript (history)
- ✅ `/api/suggest` endpoint for manual coaching (Fase 1)
- ✅ SilenceDetector for auto-triggered suggestions (Fase 1)
- ✅ `get_last_n_turns()` method in ConversationTracker (Fase 2)
- ✅ `get_recent_exchanges()` method in SessionRepository (Fase 2)

## Known Issues in v1.0

- ⚠️ Gap between Live Caption clearing and Conversation History showing text
- ⚠️ Partial text updates very rapidly (normal STT behavior)


## Rollback Procedures

### Scenario 1: Frontend Breaks After Changes
```bash
# Restore App.tsx
cp backup/v1.0/App.tsx tauri-app/src/App.tsx

# Refresh Tauri app (Ctrl+R)
```

### Scenario 2: Config Breaks
```bash
# Restore config
cp backup/v1.0/runtime_config.json python-core/runtime_config.json

# Restart backend
pkill -f "uvicorn python-core.api.server"
source .venv/bin/activate
python -m uvicorn python-core.api.server:app --host 127.0.0.1 --port 8000
```

### Scenario 3: Rust Router Breaks
```bash
# Restore router
cp backup/v1.0/router.rs tauri-app/src-tauri/src/audio/router.rs

# Rebuild Tauri
cd tauri-app
pnpm tauri dev
```

### Scenario 4: Backend Python Files Break (Fases 1-2)
```bash
# Restore all Python files from backup
cp backup/v1.0/server.py python-core/api/server.py
cp backup/v1.0/tracker.py python-core/conversation/tracker.py
cp backup/v1.0/session_repo.py python-core/storage/session_repo.py
rm python-core/pipeline/silence_detector.py

# Restart backend
pkill -f "uvicorn python-core.api.server"
source .venv/bin/activate
python -m uvicorn python-core.api.server:app --host 127.0.0.1 --port 8000
```

**What this rollback removes:**
- `/api/suggest` endpoint (manual coaching)
- `SilenceDetector` class (auto-trigger)
- `get_last_n_turns()` method
- `get_recent_exchanges()` method

### Scenario 5: Complete Rollback (All Files)
```bash
# Restore all files
cp backup/v1.0/App.tsx tauri-app/src/App.tsx
cp backup/v1.0/server.py python-core/api/server.py
cp backup/v1.0/tracker.py python-core/conversation/tracker.py
cp backup/v1.0/session_repo.py python-core/storage/session_repo.py
rm python-core/pipeline/silence_detector.py
cp backup/v1.0/runtime_config.json python-core/runtime_config.json
cp backup/v1.0/router.rs tauri-app/src-tauri/src/audio/router.rs

# Restart everything
pkill -f "uvicorn python-core.api.server"
cd /Users/dalarcon/projects/dev/interview-coach
```
