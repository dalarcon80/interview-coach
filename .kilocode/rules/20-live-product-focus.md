# Live Product Focus Rule

The current product blocker is the desktop live path.

Focus order:
1. desktop audio capture path
2. desktop-to-backend bridge
3. real STT on desktop path
4. speaker/turn correctness
5. useful live response behavior
6. latency
7. persistence/replay

Do not optimize for a teleprompter.
Do not prioritize bullets over the primary full response artifact.
Do not move to later live-product concerns while the current blocker is still alive.
